# PakCart: Integrated E-Commerce Web Application

PakCart is a full-stack e-commerce platform built with the MERN stack (MongoDB, Express.js, React, Node.js) during my full stack internship. I built it across the entire stack: UI, REST APIs, and database design. 

## Features

**Customer**
- User registration and login
- Product listings with search
- Filter bar for browsing products
- Cart management and checkout flow
- Ratings and feedback on products
- Profile page with order history

**Admin**
- Separate admin authentication
- Admin dashboard for managing the store

**Platform**
- RESTful APIs connecting the React frontend to the Express backend
- MongoDB for data persistence
- Deployed end to end

## Tech Stack
React · Node.js · Express.js · MongoDB · REST API · CSS3
